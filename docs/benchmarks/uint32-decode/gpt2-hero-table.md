## API notes

- **Tokie 0.2.0**: installed binding: Tokenizer.open(path); threads(n) only changes batch workers; encode(text) returns a uint32 numpy array.
- \*\* GigaToken 0.11.0: installed binding: Tokenizer(path); encode(text) returns a uint32 numpy array; no thread control on single-text encode.
- **HF tokenizers 0.23.3**: installed stub: Tokenizer.encode(text, add_special_tokens=False) -> Encoding; Encoding.ids is list[int]. This is the only encode API in 0.23.3.
- **HF tokenizers 1.0.0rc4**: installed 1.0.0rc4 stub: Tokenizer.compile() -> CompiledTokenizer; encode(text, add_special_tokens=False) -> Encoding; Encoding.ids is list[int]; Encoding.ids_array returns a copy. No encode_fast or ids-only method exists, and offsets are not returned unless requested, so the documented encode(...).ids path is used.
- **Kitoken 0.11.1**: installed kitoken.pyi: Kitoken.from_file(path) -> Kitoken; encode(text, encode_specials=False) -> list[int]. Default False does not match the HF ids for '<|endoftext|>'; encode_specials=True is used and disclosed.
- **tiktoken 0.14.0**: tiktoken.get_encoding('gpt2').encode(text, allowed_special=...) -> list[int]. The gpt2 ranks are the canonical OpenAI BPE; allowed_special is passed explicitly.
